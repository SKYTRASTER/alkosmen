# Инструкции для агентов

## Рабочая ветка

- Основная ветка для текущей разработки: `dev`.
- Перед началом работы переключись на `dev` и подтяни последние изменения.
- Не мержи целиком старые ветки `chatgpt/game-cursors` и `chatgpt/game-cursors-assets`.
- Не переноси изменения из старых веток вслепую: сначала сравни их с актуальным `dev`.

## Правила Git

- Имена веток писать на английском.
- Commit message, названия PR и описания PR писать по-русски.
- Не пушить изменения в `main` без отдельной явной команды пользователя.
- Текущую рабочую разработку пушить в `dev`.

## Курсоры

Нужно реализовать четыре игровых состояния курсора:

- `cursor_normal.png` — обычный курсор;
- `cursor_quest_new.png` — NPC с новым квестом;
- `cursor_quest_turnin.png` — квест можно сдать;
- `cursor_interact.png` — интерактивный объект.

Ожидаемый каталог:

`src/main/resources/alkosmen/ui/cursors/`

Рекомендуемая реализация:

- отдельный helper, например `GameCursors`;
- загрузка PNG из resources;
- создание AWT-курсоров через `Toolkit.createCustomCursor`;
- nearest-neighbor при необходимости масштабирования;
- безопасный fallback на системный курсор;
- переключение курсора при `mouseMoved` в зависимости от объекта под мышью;
- не ломать существующую логику подвала, копов, квестов и NPC.

## Приоритет сохранности изменений

Перед изменением крупных файлов, особенно `Game.java`, сначала проверь последние изменения в `dev`.
Если локальная задача конфликтует со свежими изменениями другого агента, не перезаписывай их целиком, а адаптируй патч к актуальной версии.
