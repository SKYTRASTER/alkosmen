# Алкосмен: исходник для спрайтов

`alkosmen_front_master.png` — эталонный фронтальный вид персонажа до нарезки анимаций, PNG 1086×1448 с прозрачным фоном.

## Образ

- Красная гавайская рубашка с попугаями и зелёными листьями
- Светлые шорты, белые носки, чёрные резиновые галоши
- Рюкзак ABIBAS на спине, без сумки через плечо
- Уменьшенный красный нос, уши ближе к голове, сонный взгляд

## Для будущих спрайтов

При подготовке кадров придерживаться пропорций и одежды мастер-изображения. Делать одинаковый размер кадров, фиксированную точку опоры между ступнями и прозрачный фон. Сам исходник не используется вместо анимаций в игре. Действующие спрайты расположены в `src/main/resources/alkosmen/ui/alkosmen/`.
