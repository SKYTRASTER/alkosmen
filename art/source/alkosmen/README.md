# Алкосмен: основной эталон персонажа

## Единственный утверждённый образ

**Основной исходник:** [alkosmen_front_master.png](./alkosmen_front_master.png) (1086×1448, PNG, прозрачный фон).

Все игровые спрайты и новые ракурсы должны соответствовать **одному и тому же герою**:

- Красная гавайская рубашка с попугаями и зелёными листьями.
- Светлые шорты, белые носки, чёрные резиновые галоши.
- Рюкзак **ABIBAS** на спине; сумки через плечо нет.
- Уменьшенный красный нос, уши ближе к голове, сонный взгляд.
- Постоянные форма головы, причёска, рост, пропорции и палитра.

## Решение от 21.10.2026: один персонаж для всех направлений

Второй ранее показанный в переписке референс (белая одежда, коричневая сумка через плечо, профиль влево) **отклонён и исключён из активных референсов**. Не копировать из него **ни внешность, ни одежду, ни обувь, ни сумку, ни стиль**. Сведения об отклонённом варианте: [архив решений](../../archive/alkosmen/README.md).

Для `idle_front`, `idle_back`, `idle_left`, `idle_right`, `walk_front`, `walk_back`, `walk_left`, `walk_right` и дополнительных анимаций требуется одинаковый образ. Направления и фазы шага можно менять, дизайн персонажа нельзя.

Боковой профиль влево строится **из утверждённого Алкосмена**, а не из персонажа с другого референса. Ходьба должна содержать плавные последовательные фазы шага с одинаковой точкой опоры и постоянным масштабом.

## Технические требования

- Одинаковые размеры кадров, единая опора между ступнями, прозрачный фон.
- Перед интеграцией проверять шесть или более фаз походки без изменения одежды между кадрами.
- Главный исходник **не** использовать как анимацию напрямую.
- Активные игровые PNG: `src/main/resources/alkosmen/ui/alkosmen/`.
- Текущие кадры не изменялись этим решением; существующую анимацию проверять отдельно перед заменой.
