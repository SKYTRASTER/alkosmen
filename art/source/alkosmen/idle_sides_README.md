# Боковые idle-анимации Алкосмена

В игровых ресурсах `src/main/resources/alkosmen/ui/alkosmen/idle_right/` и `idle_left/` по 6 PNG (`00.png`–`05.png`).

- Каждая картинка 384×752, RGBA с прозрачным фоном
- Правый вид получен нарезкой sprite sheet и помещён по центру без масштабирования; уровень нижней точки изображения одинаков
- Левый вид — покадровое горизонтальное отражение правого, без новой генерации
- Сохранены рюкзак, красная гавайская рубашка, шорты и чёрные галоши
- Длительности кадров для предварительного просмотра: 190, 190, 210, 190, 190, 210 мс, цикл бесконечный
- PNG пока добавлены только как ресурсы, код переключения idle для тестовых сцен не менялся

`idle_front` и `idle_back` не затронуты.

## Ходьба влево и вправо (21.10.2026)

- Код игры теперь загружает эти утверждённые `idle_left` / `idle_right` как исходники боковой ходьбы.
- `SideWalkGait` формирует 6 осторожных фаз шага из нижней части каждого PNG при загрузке сцены. Верхняя часть (лицо, рубашка, рюкзак) не меняется.
- `AlkosmenWalkAnimation` использует разные изображения для LEFT и RIGHT, без зеркалирования чужого персонажа.
- При остановке и столкновении с препятствием включается соответствующий `idle_*`.
- Старые кадры `walk_right_v2` с белым костюмом перенесены в `art/archive/alkosmen/white-outfit-walk-right/` и не используются в игре.
- Проверка расчёта фаз: `./gradlew verifySideWalkGait`. Интерактивная проверка: `./gradlew runAlkosmenWalk`.
- Генерируемая в коде походка предварительная: художественную плавность следует оценить в игре, затем при необходимости заменить на нарисованные отдельные PNG.
