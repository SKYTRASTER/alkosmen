# Алкосмен — подготовка к моделированию в Blender

Рабочая ветка: `art/alkosmen-3d-reference`.

## Принятый внешний вид

- Лицо ближе к референсу 2026-11-26: короткие кудрявые тёмные волосы, щетина, более реалистичные пропорции.
- Красная гавайская рубашка в цветок, светлые шорты, белые носки, чёрные ботинки.
- Рюкзак `ABIBAS`.

## Референсы / исходники

Готов пакет `alkosmen_blender_starter.zip` в чате ChatGPT с файлами:

- `alkosmen_3d_turnaround.png` — спереди/профиль/сзади;
- `alkosmen_ref_front.png`, `alkosmen_ref_side.png`, `alkosmen_ref_back.png`;
- `setup_alkosmen_blender.py` — создаёт референсы в Blender, простую объёмную заготовку, свет и камеру;
- `README_RU.md` — инструкция запуска.

**ВАЖНО:** бинарные PNG и скрипт из архива ещё **не загружены** в GitHub; этот README только фиксирует согласованный источник и процесс. Нельзя считать, что в ветке уже есть рабочая `.blend` или `.glb` модель.

## Что делать

1. Распаковать пакет.
2. Открыть Blender (4.2+), вкладку `Scripting`, загрузить `setup_alkosmen_blender.py` и выполнить `Run Script`.
3. Проверить и сохранить автоматически создаваемый `alkosmen_3d_start.blend`.
4. Продолжить моделирование: геометрия, UV, текстуры, риг, анимация.
5. После готовности экспортировать `.glb` для libGDX.

Никаких изменений в ветку `dev-libgdx` до проверки модели.
