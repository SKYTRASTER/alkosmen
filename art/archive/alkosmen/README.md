**Статус:** отклонён. Не использовать для генерации, редактирования или тестирования спрайтов главного героя.

Это второй референс из обсуждения 21.10.2026: другой персонаж в белой одежде и с сумкой через плечо. Первоначально он использовался как пример поворота влево, но приводил к подмене внешности Алкосмена. Пользователь исключил картинку из дальнейшей работы.

**Файл исходного изображения в GitHub отсутствует.** Этот документ фиксирует архивное решение, а не утверждает, что бинарное изображение перемещено сюда.
