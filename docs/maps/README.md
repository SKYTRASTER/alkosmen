# Референс карты: Новый парк (Зуевка)

Рабочая ветка: `dev-libgdx`.

- `map-layout.json`: черновой набор опорных точек улиц, координаты в пикселях исходного скриншота 1336×885.
- `new_park_reference.png`: оригинальный скриншот карты из разговора, должен лежать рядом с этим файлом.
- Ось пикселей начинается в левом верхнем углу. В libGDX Y направлен вверх, требуется преобразование.
- Данные предназначены только для согласования дорожного каркаса. Это НЕ точная GIS-карта.
- Не возвращать старое цельное изображение NewPark в качестве игрового фона.
