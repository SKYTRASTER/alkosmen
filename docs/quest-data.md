# Квесты и маршруты в SQLite

Локальная база находится в `%APPDATA%\Alkosmen\save.sqlite`. Перед ручным редактированием закрой игру и сделай копию файла. При первом запуске таблицы заполняются из `src/main/resources/alkosmen/data/*.tsv`. Повторный запуск не перезаписывает уже существующие строки: правки в SQLite сохраняются. Для обновления встроенных данных у существующих игроков нужна отдельная миграция.

| Таблица | Что хранит |
| --- | --- |
| `npc_routes` | Маршруты и паузы NPC; стартовые данные в `npc_routes.tsv` |
| `npc_quest_offers` | Порядок квестов NPC и ключи окон/финальных реплик |
| `dialogue_texts` | Все тексты; стартовые данные в `quest_dialogues.tsv` |
| `quest_steps` | Координаты и реплики точек НЛО, тайников «Тича» и входа в подвал |
| `quest_scene_stages` | Цель и подпись каждого этапа подвала |
| `quest_scene_targets` | Координаты, размер и радиус взаимодействия с объектами подвала |
| `quest_scene_events` | Действие при клике/E, следующий этап и реплика |
| `quest_progress`, `quest_stages`, `quest_collections` | Личное сохранение игрока, отдельно от сценариев |

В `quest_scene_events` допустимы действия `LINE` (только реплика), `ADVANCE` (сохранить следующий этап) и `EXIT` (выйти из сцены). Строка для `tolya` с этапом 2 отвечает за сдачу расписки; этап 3 означает, что Толя её получил. Серебристый `?` висит над Толей, пока квест активен, золотой `?` появляется при готовности к сдаче.

Код остаётся исполнителем механик: проверяет расстояние, рисует цели, обрабатывает клики и сохраняет прогресс. Координаты, порядок существующих квестов, тексты, маршруты и переходы подвала задаются данными. Новый **тип** механики (не просто новые шаги или реплики) всё ещё потребует обработчик в Java; произвольный код из базы игра не выполняет.
