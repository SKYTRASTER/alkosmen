# Общие текстуры «Алкосменов»

Папка для повторно используемых визуальных ресурсов города: земля, дороги, тротуары, брусчатка, клумбы, здания.

Планируемые концепты:
- `ground_tiles_concept.png` — покрытия: трава, грунт, асфальт, плитка, бордюры.
- `urban_tiles_concept.png` — городские объекты: брусчатка, клумба, пятиэтажка.
- `street_style_reference.png` — визуальный эталон улицы.

**Важно:** изображения пока не загружены в Git. Не указывать эти пути в коде до появления файлов. Исходные изображения концептуальные, это ещё не готовые тайлы фиксированной сетки 16×16.
