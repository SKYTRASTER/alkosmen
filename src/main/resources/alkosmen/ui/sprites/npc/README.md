# NPC sprite sheets

Игровые спрайты для сюжетных персонажей Кирова и электрички.

Все PNG подготовлены как сетка 4×4 размером 1254×1254.
Фон прозрачный. Для отрисовки используйте nearest-neighbor scaling.

Файлы:
- red_brother.png — Рыжий, семейка на Чапаева;
- red_sister.png — Рыжая, семейка на Чапаева;
- dnb_partygoer.png — участник DnB-тусовки;
- train_gopnik.png — гопник из электрички;
- train_conductor.png — контролёр/кондуктор электрички;
- suspicious_stranger.png — подозрительный третий участник/заготовка под Шкалика.

Сейчас в игре используется верхняя строка как анимация ожидания. Остальные строки оставлены для будущих действий.
